관리자 화면 캡처는 FE Phase 10(관리자 화면 수정) 뒤에 교체한다.

## 가입 승인

- 이름·전화번호를 입력한 대기 회원만 승인 목록에 보인다.
- 승인하면 활성, 거절하면 비활성 + 거절 사유 기록. 거절된 회원을 되돌리려면 상태를 대기로 바꾼다.

## 회원과 이용권

- 이름 또는 전화번호로 검색한다. 상태(대기·활성·휴회·비활성) 필터가 있다.
- 회원 상세에서 이용권 등록, 횟수 가감(0.5 단위, 사유 필수), 기간 수정, 등록 취소를 한다.
- 등록 시 시작일을 지정할 수 있다(과거 허용). 기간·유효기간 변경은 전후 값과 사유가 이력으로 남는다.
- 등록 취소는 그 이용권으로 잡힌 활성 예약이 없어야 한다. 예약을 먼저 정리한다.
- 가감으로 잔여가 음수가 되는 요청은 거부된다. 기간제 회비는 횟수 가감 대상이 아니다.

## 주간 보드와 명단

- 셀을 누르면 그 타임의 예약자 명단이 열린다.
- 대리 취소·변경은 당일에도 가능하다. 취소 시 차감 복구 여부를 고른다(기본 복구).
- 예약제·1:1 수업은 예약자에 대해 출석/불참을 체크한다. 저녁반은 회원을 검색해 명단에 추가하고, 추가됨 = 출석이다.
- 저녁반에 횟수권 회원을 추가하면 0.5회가 차감된다(회비가 있으면 차감 없음). 삭제하면 자동 복구된다.
- 소급 입력·수정이 된다. 단, 이미 실행된 2주 미사용 차감은 되돌리지 않는다. 필요하면 수동 가감으로 정정한다.

## 휴강

특정 날짜의 특정 수업을 휴강 처리하면 그 타임 예약이 전부 취소되고 차감이 복구되며 회원에게 알림이 간다.

## 공지와 알림

- 공지는 작성·수정·삭제. 회원 화면에 목록과 상세가 보인다.
- 알림센터는 30초마다 새 알림을 확인한다. 활동 피드에서 최근 예약·취소·승인 이력을 본다.

## 2주 미사용 차감 배치

- 배치는 배포 시 기본 꺼짐이다. 켜는 절차는 세 단계다. 출석 배선 확인 → 수동 실행 1회로 결과 검증 → 환경변수로 활성화.
- 관리자 수동 실행 API는 언제나 동작한다. 실행 중에 다시 실행하면 409로 거부된다.
- 이상이 보이면 환경변수를 끄고 재배포하면 즉시 멈춘다. 이미 된 차감은 수동 가감으로 정정한다. 배치는 환불하지 않는다.
