# gold-wrestling-docs

골드레슬링 프로젝트의 포트폴리오·문서 사이트 (VitePress, GitHub Pages).

- 배포: https://minsu-zip.github.io/gold-wrestling-docs/
- 원본 레포: [gold-wrestling-fe](https://github.com/minsu-zip/gold-wrestling-fe) · [gold-wrestling-be](https://github.com/minsu-zip/gold-wrestling-be)

```bash
pnpm install
pnpm docs:dev       # http://localhost:5173/gold-wrestling-docs/
pnpm docs:build
pnpm docs:preview
```

`tech/policies.md`·`glossary.md`·`error-codes.md`·`decisions.md`는 BE 레포 `docs/`에서 이관한 사본이다.
원본이 바뀌면 다시 복사한다. 스크린샷 촬영 목록은 `CAPTURE-LIST.md`.
